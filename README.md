# 🎣 Friendslop Fishing Co.

> A high-stakes, chaotic co-op fishing roguelite with physical deck comedy, dual-screen tactile phone controllers, and secret sabotage contracts.

---

## 🎮 Core Features

- **The 15-Minute Roguelite Loop**: 5 escalating levels (Sweetwater Pond $\rightarrow$ Industrial Coast $\rightarrow$ Abyssal Trench $\rightarrow$ The Maelstrom $\rightarrow$ The Eldritch Kraken).
- **Physical Deck Balance & Dynamic Waves**: Keep the boat balanced or risk capsizing!
- **30-Second Dredged Crate Draft**: End-of-level team vote with single currency bank and Gary Coin Flip tie-breakers.
- **Corporate Contracts Generator**: Deck-gated contracts with $3\times$ recency bias for newly purchased stations.
- **Uncle Gary's Gated Secret Bounties (Gary-OS)**: Private sabotage missions with plausible alibis.
- **9 Tactile Minigames**: 100% parity between mobile single-finger touch and PC single-click mouse.
- **Dual-Audio Architecture**: Mixed TV soundscape + intimate personal phone micro-SFX (squeegee squeaks, sizzling oil, retro Nokia beeps, and Web Haptics).
- **Grand Endgame Audit**: Crowning **Employee of the Run (MVP)** and **Uncle Gary's Golden Rat (Top Saboteur)**.

---

## 🚀 Getting Started

```bash
# Install dependencies
npm install

# Start local development server
npm run dev
```

Open `http://localhost:5173` in your browser.
